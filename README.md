# NeoCam

**NeoCam** — ультра-быстрая флагманская камера на Android (Jetpack Compose + CameraX + Camera2 Interop + ML Kit) в дизайне **Obsidian Black + Electric Blue Neon**.

**Author:** [DimSimd](https://github.com/DimSimd2020)

---

## Ключевые особенности

- **Zero-Shutter-Lag (0 мс задержка спуска)** и **Instant RAM Review («Нажал — сфоткало — сразу посмотрел»)**:
  - Кадр захватывается в оперативную память в миллисекунду нажатия кнопки затвора и сразу доступен для полноэкранного просмотра с зумом до завершения фоновой записи в `MediaStore` (`DCIM/NeoCam`).
  - Галерея открывается поверх активной сессии камеры без `unbindAll()` — вход и возврат к видоискателю занимают **0 мс**.
- **Оптимизированные флагманские профили** (автоопределение + переключение в настройках):
  - **Google Pixel 8**: `0.5x` Ultra-Wide с автофокусом и `Авто-Макро`, `1x` (50 МП Octa PD), `2x` оптический кроп, `Super Res Zoom` до `8x` / `30x` с радаром стабилизации.
  - **Samsung Galaxy S25 Ultra**: квадро-система `0.6x / 1x (200 МП) / 2x / 3x Tele / 5x Periscope` и `100x Space Zoom` с радар-картой.
  - **Samsung Galaxy Z Flip 7**: автоматический режим **`FlexCam 90°`** по датчику сгиба шарнира (`TYPE_HINGE_ANGLE`) и формат `1:1`.
  - **Poco X8 Pro**: `50 МП` High-Res и `30x` супер-зум.
- **Умный ИИ-Аимбот (`AimController` + ML Kit)**:
  - Автоматическое удержание цели в фокусе, выбор объекта касанием по экрану и автоспуск при стабилизации кадра.
- **Режим PRO**:
  - Ручное управление `ISO`, выдержкой (`1/4000` – `8с`), экспокоррекцией (`EV`), ручным фокусом (`AF / MF ∞..Макро`) и балансом белого (`WB`) с живой телеметрией сенсора.
- **Встроенная галерея и плеер Media3 ExoPlayer**:
  - Просмотр фото (мультитач-зум до `6x`) и видео, подробные `EXIF`-метаданные (`Artist: DimSimd`, `Software: NeoCam by DimSimd`), экспорт и импорт.

## Сборка и установка

```bash
./gradlew assembleRelease
adb install -r app/build/outputs/apk/release/app-release.apk
```


## Обновления

Начиная с **v2.2**, NeoCam проверяет опубликованные GitHub Releases при запуске (не чаще
одного раза в 12 часов). В настройках есть кнопка ручной проверки.
APK скачивается **только с согласия пользователя**. Перед установкой приложение
проверяет SHA-256, package ID, номер версии и подпись APK. Установку подтверждает Android.

**Подпись APK:** текущая конфигурация GitHub Actions подписывает сборки временным
debug-ключом. Для обновлений поверх установленной версии понадобится один постоянный
релизный ключ в GitHub Secrets, а после перехода на него — однократная переустановка.
Приватный ключ нельзя коммитить в публичный репозиторий.

### Постоянная подпись APK для обновления без удаления приложения

Создайте приватный release keystore один раз, храните его в безопасном месте.
Настройте в GitHub Actions Secrets репозитория:
`NEOCAM_KEYSTORE_BASE64` (base64 содержимого keystore),
`NEOCAM_STORE_PASSWORD`, `NEOCAM_KEY_ALIAS`,
`NEOCAM_KEY_PASSWORD`.
Workflow воспользуется ими автоматически. Если секреты не заданы, он сохранит
старую debug-подпись, несовместимую между новыми CI-запусками. Не добавляйте
файл keystore и пароли в git.
